# reputversorger — Testseite

Statische Testseite (nur `index.html`, keine Abhängigkeiten außer Google Fonts via CDN).

## Deployment via GitHub Pages

1. Diese Dateien in das Repo `reputversorger-website` hochladen (root-Verzeichnis, oder in einen `docs/`-Ordner).
2. Im Repo: Settings → Pages → Source auf `main` Branch (und ggf. `/docs`) stellen → Save.
3. Nach 1-2 Minuten ist die Seite unter `https://<username>.github.io/reputversorger-website/` erreichbar.
